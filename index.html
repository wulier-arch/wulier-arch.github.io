关于

现有的 JavaScript 深度学习库基本是 TensorFlow.js / ONNX 的封装。你没法在不装依赖的前提下 读懂它们的反向传播，也没法在浏览器里断点进去看梯度是怎么流回去的。

我做的事情是另一条路：从零手写，并且把正确性摊开给你看。 写 axon 的过程中，有限差分梯度校验抓到过三个静默 bug——前向传播全都正确， 只有数值梯度能发现权重在错误地训练。这类问题跑测试发现不了，却最伤可信度。

同样的取向也用在工程习惯上：零依赖、零构建，克隆下来就能跑； 文档里的每个数字都能用仓库里的脚本复现。

项目

axon

零依赖神经网络框架

自动微分、张量运算、卷积、层、优化器与训练循环，全部手写。 同一份代码在浏览器和 Node.js 里都能跑。

0依赖
57导出
114测试
2.36GFLOP/s
核心主张是梯度可验证：每个算子都自带有限差分对照，梯度错了立刻暴露， 而不是「跑起来没报错就算对」。性能上比 TensorFlow.js 慢一个数量级， 这是刻意的取舍——换来的是每一行都能读懂。

rope-embedding

零依赖旋转位置编码

RoPE 的独立实现，从数学定义手写。内置性质自检——正交性、范数保持、 相对位置不变性全部数值验证，误差触到双精度机器 epsilon。 两种配对约定（half / interleaved）都实现， 因为接错会静默出错。
